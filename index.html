The rules

  1. Ask every client, every job. Once it's finished. If anything is still open, fix it first, then ask.
  2. Never offer anything for a review. No discounts, gifts or prize draws. It breaks Google's review rules.
  3. Never write a review for a client, or ask friends and family to post one.
  4. Three touches max. Day 0, Day 3, Day 7. Then stop.
  5. Send from GHL between 8am and 6pm, so everything is logged against the client.
